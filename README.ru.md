# ComfyUI-ImageLoaderPlus v0.1.7 (test build)

Компактная нода загрузки изображений для ComfyUI с отдельным менеджером файлов в стиле **ComfyUI-PromptLora**. Галерея работает исключительно с изображениями в `ComfyUI/input` и вложенных папках.

## Возможности

- Выбор изображения из отдельного окна менеджера: миниатюры **S/L**, приватный текстовый список, поиск и папки слева.
- В приватном режиме **никакие миниатюры не создаются в интерфейсе**. Режим просмотра запоминается после перезапуска.
- Предпросмотр вписывается в размеры ноды, не обрезается и не изменяет её размеры.
- В ноде четыре кнопки: **Вставить из буфера**, **Очистить выбор**, **Скрыть/показать предпросмотр**, **Открыть менеджер**. Подсказки появляются при наведении.
- Ctrl+V на выделенной ноде вставляет вместо создания новой Load Image; также поддерживаются кнопка вставки и перенос файла на ноду.
- Возвращает стандартные выходы `IMAGE` и `MASK`.
- **Выбранное изображение не сохраняется в workflow**: после открытия проекта и перезапуска ComfyUI выбор сбрасывается. Файлы на диске не меняются от такого сброса.

## Новое в v0.1.7: отдельные списки для каждой папки

- Левая верхняя папка теперь называется **📁 input**, а не «Все изображения».
- При выборе **input** отображаются только изображения, лежащие непосредственно в `ComfyUI/input`; файлы из подпапок в этот список больше не попадают.
- При выборе любой подпапки отображаются только изображения в ней самой, без файлов её вложенных подпапок.
- Число справа от папки показывает **только количество картинок непосредственно в этой папке**.
- После переноса изображений менеджер остаётся в исходной папке, чтобы было сразу видно, что картинки из неё исчезли. Для просмотра перенесённых файлов выберите папку назначения слева.
- Поиск работает в выбранной папке; в приватном списке показываются простые имена файлов без префиксов папок.

## Новое в v0.1.6: организация файлов

В менеджере добавились **значок создания папки** и **значок режима управления файлами** (квадрат с галочкой).

### Создать подпапку

1. Слева выберите нужную папку или **input** (корень `input`).
2. Нажмите значок **папки с плюсом** в верхней строке.
3. Введите имя и нажмите **Создать**.

Новая папка появится слева даже если она пока пустая. Можно создавать и вложенные папки.

### Перенести одно или несколько изображений

**Способ 1 — выделение:**

1. Нажмите значок **режима управления** (квадрат с галочкой) в верхней строке.
2. Отметьте нужные картинки обычными кликами. Выделение не закрывает менеджер.
3. Нажмите **Переместить…** и выберите папку из списка.

**Способ 2 — перетаскивание:** возьмите изображение мышью и перетащите на папку в левой колонке. Подтвердите перенос. Если в режиме управления выделено несколько изображений, перетаскивание выделенного элемента перенесёт их вместе.

**Быстрый вход в управление:** нажмите правой кнопкой мыши на изображение — оно выделится, и откроется панель управления файлами.

Если в папке назначения уже есть файл с тем же именем, переносимый файл **не перезапишет его**: будет добавлен суффикс `_1`, `_2` и т. д.

### Удалить ненужные изображения

1. Включите режим управления (квадрат с галочкой), выделите изображения.
2. Нажмите **В корзину** и подтвердите действие.

Файлы **не удаляются безвозвратно**. В Windows они отправляются в Корзину, откуда их можно восстановить. Если Корзина недоступна (например, для некоторых сетевых дисков), операция выдаст ошибку, а не перейдёт к безвозвратному удалению.

**Важно:** при перемещении или удалении файла ранее сохранённые workflow, ссылающиеся на старый путь, могут перестать находить его. Перенос выбранного изображения обновляет путь в текущей ноде; сохранённые старые workflow автоматически не переписываются.

Обычный щелчок в режиме просмотра по-прежнему **выбирает картинку для ноды и закрывает менеджер**, как в v0.1.5. Режим управления файлами включается только явно.

## Установка / обновление

1. Закройте ComfyUI.
2. Замените всю папку `ComfyUI-ImageLoaderPlus` в `ComfyUI/custom_nodes` новой папкой из ZIP.
3. Запустите ComfyUI, обновите браузер через **Ctrl+F5**.
4. Добавьте ноду **ImageLoaderPlus** из категории **image / ImageLoaderPlus**.

Специально устанавливать библиотеки в Windows обычно не нужно: для отправки в Корзину сначала используется `send2trash`, если установлен, иначе штатный Windows Shell API. Для Linux/macOS безопасное удаление потребует `send2trash` (`pip install send2trash` в venv ComfyUI). Остальные зависимости входят в ComfyUI.

## Безопасность и ограничения

- Операции изменения файлов ограничены папкой `input`, не принимают `..`, абсолютные пути и символические ссылки.
- Удаление требует явного подтверждения и осуществляется через Корзину, без скрытого окончательного удаления.
- За одну операцию разрешено до 200 изображений; галерея отображает до 5000 файлов.
- Поддерживаются PNG, JPG, WEBP, BMP, GIF, TIFF; анимированные GIF/TIFF загружаются первым кадром.
- Файлы из `input` используются другими workflow и нодами; удаляйте их осознанно.
- Сначала тестируйте перенос/удаление на ненужной копии картинки.

**Тестовая версия:** проверены Python-функции файловых операций и имитация интерфейса в Chromium. Реальная версия ComfyUI пользователя требует отдельной проверки.
