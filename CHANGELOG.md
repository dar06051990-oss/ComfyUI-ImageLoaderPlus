# Changelog

## 1.0.0 — Per-folder gallery

- Changed the top-level gallery entry from “All images” to `input`.
- Show files and image counts for the selected folder only (not nested folders).
- Keep the source folder active after moving images.
- Search in the current folder; show bare file names in private list mode.

## 0.1.6 — File organizer

- Create subfolders, including nested and empty folders.
- Multi-select and move images; drag images onto folders.
- Send files to the Recycle Bin/Trash (never deliberately delete permanently).
- Resolve destination collisions by appending a numeric suffix.

## 0.1.5 and earlier — Loader and gallery

- Floating gallery and text-only private list.
- Paste and drop support; standard `IMAGE` and `MASK` outputs.
- Non-persistent image selection and in-node image preview.
